# Code of Conduct

This project follows the [Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

The full text is canonical at the link above. The summary, for the impatient:

- Be respectful. Critique the work, not the person.
- Assume good faith. Ask clarifying questions before escalating.
- Harassment, discrimination, and personal attacks are not tolerated.
- Maintainers will enforce.

## Reporting

Report concerns to **conduct@weft.dev**. Reports are confidential. Maintainers will respond within 7 days.

## Enforcement

Maintainers may, at their discretion:

1. Issue a private warning.
2. Require a public apology.
3. Temporarily ban the contributor from the repo (issues, discussions, PRs).
4. Permanently ban.

Bans are appealable in writing to the same email after 90 days.

## Scope

This applies to all project spaces: this repo's issues, PRs, discussions, the `weft-*` npm registry pages where comments are possible, and any public communication that explicitly references this project.
